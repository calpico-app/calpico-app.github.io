カルピコアプリ

マスターズ水泳チーム「カルピコ」のメンバー向けアプリです。

できること

  • 自分の残高（前払い金からエントリー費・年会費などを引いた残り）と、年ごとの明細を確認する
  • 大会のレース動画をアップロードし、チームのメンバーと見返す

使える人

カルピコのメンバーだけが使えます。アカウントはチームの管理者が作成します。アプリから新しく登録することはできません。

YouTube の利用について

動画の保存と再生に YouTube API サービスを使っています。動画はチーム用の YouTube チャンネルに「限定公開」で保存されます。
