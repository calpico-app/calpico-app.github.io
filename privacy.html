プライバシーポリシー

カルピコアプリ

制定日: 2026年10月27日 ／ 最終更新日: 2026年10月27日

カルピコ アプリ担当（以下「運営者」）は、マスターズ水泳チーム「カルピコ」のメンバー向けアプリ「カルピコアプリ」（以下「本アプリ」）で扱う情報について、次のとおり取り扱います。

1. 取得する情報

情報取得のしかた
氏名、登録番号、ログイン ID管理者がアカウントを作るときに登録します
パスワードご本人が設定します。復元できない形（ハッシュ）で保存し、運営者も見ることはできません
残高と入出金の明細（繰越、入金、エントリー費、年会費、事務費など）チームの会計担当が管理するスプレッドシートから、管理者の操作で取り込みます
動画、動画に付けたタグ（泳いでいる人、種目・距離など）メンバーがアップロード・入力します
アプリの異常終了の記録（端末の機種、OS のバージョン、アプリのバージョン、エラーの内容など）Firebase Crashlytics により自動で送られます

本アプリでは、メールアドレス、電話番号、位置情報、連絡先は取得しません。

2. 利用目的

  • メンバーご本人が自分の残高と明細を確認できるようにするため
  • チームのメンバー同士で大会の動画を共有し、見返せるようにするため
  • ログインとアカウントの管理のため
  • 不具合の調査と改善のため

3. 情報を見られる人

  • 残高と明細: ご本人と、チームの管理者
  • 氏名: チームのメンバー全員（動画のタグ付けに使うため）
  • 登録番号、ログイン ID: チームの管理者
  • 動画とタグ: チームのメンバー全員

動画は、チーム用の YouTube チャンネルに「限定公開」で保存します。本アプリでは動画の URL を表示しませんが、限定公開の動画は URL を知っている人なら誰でも見られる仕組みのため、URL がチームの外に伝わった場合は、メンバー以外の人も見られることがあります。

4. 外部サービスの利用

本アプリは次のサービスを使っており、各サービスに情報が送られ、保存されます。

サービス用途
Supabase（Supabase, Inc.）アカウント、メンバー情報、残高と明細、タグの保存
YouTube API サービス（Google LLC）動画の保存と再生
Google Sheets API（Google LLC）会計スプレッドシートからの残高の取り込み
Firebase Crashlytics（Google LLC）アプリの異常終了の記録

本アプリは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約 が、Google による情報の取り扱いには Google プライバシーポリシー が適用されます。

これらのサービスのサーバーは日本国外にある場合があります。

Google ユーザーデータの取り扱い

本アプリが Google のアカウントにアクセスするのは、運営者が管理するチーム用の YouTube チャンネルだけです。メンバー個人の Google アカウントにはアクセスしません。チーム用チャンネルに対しては、動画のアップロード、アップロードした動画がチャンネルにあるかの確認、動画の削除だけを行います。YouTube API サービスから得た情報は、これらの目的にだけ使い、第三者に提供したり広告に使ったりしません。チーム用チャンネルの許可は、Google アカウントのセキュリティ設定 からいつでも取り消せます。

5. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく第三者に提供しません（上の外部サービスへの保存を除きます）。

6. 保存期間と削除

  • アプリの設定から、ご本人がアカウントを削除できます。削除すると、アカウント、残高と明細、「泳いでいる人」のタグが削除されます。アップロードした動画はチームの記録として残ります。消したい動画は、アカウントを削除する前にご本人が削除できます。
  • 管理者が退会の手続きをした場合は、ログインできなくなり、残高と明細が削除されます。動画とタグは残ります。
  • 動画の削除を希望する場合は、アップロードした本人または管理者が削除できます。管理者への依頼も受け付けます。
  • 会計の記録そのものは、チームの会計担当が管理するスプレッドシートに残ります。

7. 安全管理

通信は暗号化し、データには必要な人だけがアクセスできるよう権限を設定しています。

8. 開示・訂正・削除のご依頼

ご自身の情報の開示・訂正・削除を希望される場合は、下記のお問い合わせ先か、チームの管理者にご連絡ください。

9. このポリシーの変更

内容を変更する場合は、このページでお知らせします。
