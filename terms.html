利用規約

カルピコアプリ

制定日: 2026年10月27日 ／ 最終更新日: 2026年10月27日

この規約は、カルピコ アプリ担当（以下「運営者」）が提供するアプリ「カルピコアプリ」（以下「本アプリ」）の利用条件を定めるものです。

1. 利用できる人

本アプリは、マスターズ水泳チーム「カルピコ」のメンバーで、管理者がアカウントを作成した人だけが利用できます。ログイン ID とパスワードは他人に教えないでください。

2. 動画のアップロード

  • アップロードできるのは、チームが参加した大会の動画だけです。
  • 映っている人が嫌がる動画は上げないでください。削除を頼まれたら、上げた本人または管理者が削除します。
  • 動画はチーム用の YouTube チャンネルに限定公開で保存されます。動画の URL をチームの外に広めないでください。
  • 本アプリは YouTube API サービスを利用しています。本アプリを利用することで、YouTube 利用規約 にも同意したものとみなします。

3. 禁止事項

  • 他人のアカウントを使うこと
  • 本アプリで知った他のメンバーの情報を、チームの外に広めること
  • 本アプリの運営を妨げること
  • 法令や公序良俗に反すること

4. 残高の表示について

本アプリの残高と明細は、会計担当が管理するスプレッドシートを取り込んだものです。取り込みは月1回程度のため、最新の状態と異なる場合があります。正式な記録はスプレッドシートです。

5. 提供の中断・終了

不具合や保守のため、予告なく本アプリを止めることがあります。また、運営者の判断で本アプリの提供を終了することがあります。

6. 免責

運営者は、本アプリの利用によって生じた損害について、運営者の故意または重大な過失による場合を除き、責任を負いません。

7. 規約の変更

この規約を変更する場合は、このページでお知らせします。
